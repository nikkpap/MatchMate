# MatchMate 🔔

Android εφαρμογή προσωπικού προγράμματος αθλητικών τηλεοπτικών μεταδόσεων.
Ελληνικό περιβάλλον, Material 3, Kotlin και Jetpack Compose.

## Τι νέο στην 0.3.0

### Διορθώσεις σφαλμάτων
- **Απώλεια ρυθμίσεων:** αν το αποθηκευμένο πρόγραμμα (cache) χαλούσε, η εφαρμογή φόρτωνε κενές
  προτιμήσεις και η επόμενη αλλαγή **έσβηνε τις ομάδες σου**. Τώρα ρυθμίσεις και cache φορτώνονται χωριστά·
  μια κατεστραμμένη εγγραφή παραλείπεται χωρίς να χαθεί όλο το πρόγραμμα.
- **«null» στην οθόνη:** κενές τιμές της πηγής (`description`, κανάλι, `displayName`) εμφανίζονταν ως «null».
- **Επανάνοιγμα μετάδοσης σε περιστροφή:** μετά από άνοιγμα από ειδοποίηση, η περιστροφή ξανάνοιγε τις λεπτομέρειες.
- **Λίστες που μεγάλωναν για πάντα:** τα IDs κουδουνιών/σίγασης/αστεριών παλιών μεταδόσεων δεν σβήνονταν ποτέ.
  Καθαρίζονται μετά από κάθε επιτυχή ανανέωση (ποτέ με κενό πρόγραμμα).
- **«Σε 29 λεπτά» αντί για 30:** στρογγυλοποίηση προς τα πάνω στο κείμενο ειδοποίησης.
- Το μήνυμα σφάλματος κλείνει πλέον με «Κλείσιμο» και καθαρίζει σε κάθε επιτυχή αλλαγή.
- Η κάρτα «Επόμενη μετάδοση» δείχνει μόνο δική σου μετάδοση (όχι τυχαία, όταν δεν υπάρχει).
- Ασφαλές άνοιγμα ρυθμίσεων Android (χωρίς crash σε συσκευές που δεν έχουν τη σελίδα).
- Χωρίς σκοτεινό «φλας» στην εκκίνηση όταν έχεις φωτεινό θέμα.

### Γλώσσα GR / EN
- Ολόκληρη η εφαρμογή και οι ειδοποιήσεις σε **Ελληνικά ή Αγγλικά**, άμεση αλλαγή χωρίς επανεκκίνηση.
- Επιλογή γλώσσας στο **Σχετικά** (Ρυθμίσεις → Σχετικά, και από το εικονίδιο ⓘ πάνω δεξιά).

### Δυναμικά θέματα
- Λειτουργίες: **Σύστημα / Φωτεινό / Σκοτεινό / AMOLED** (καθαρό μαύρο).
- Χρώματα: **Μέντα, Ωκεανός, Ηλιοβασίλεμα, Βιολετί, Γήπεδο, Χρυσό** και **Material You** (Android 12+).
- Η αλλαγή εφαρμόζεται αμέσως με ομαλή μετάβαση χρωμάτων σε όλη την εφαρμογή· και οι ειδοποιήσεις παίρνουν το χρώμα.

### Νέες λειτουργίες
- **Κανάλια:** νέα καρτέλα στις Επιλογές — ξετσέκαρε όσα κανάλια δεν έχεις (π.χ. συνδρομητικά).
  Κρύβονται από το πρόγραμμα και δεν δίνουν αυτόματες υπενθυμίσεις (το χειροκίνητο κουδουνάκι ισχύει).
  Γρήγορα και από τις λεπτομέρειες: «Δεν έχω το …».
- **Σίγαση από την ειδοποίηση:** κουμπί «Σίγαση αγώνα» ακυρώνει και τις υπόλοιπες υπενθυμίσεις του.
- **Ημερολόγιο** και **Κοινοποίηση** μετάδοσης από τις λεπτομέρειες.
- **Αντίγραφο ασφαλείας:** Εξαγωγή / Εισαγωγή ρυθμίσεων σε αρχείο JSON (νέο κινητό ή επανεγκατάσταση).
- **Τράβηγμα προς τα κάτω** για ανανέωση.
- Ένδειξη **«Σε εξέλιξη»** (παλμική κουκκίδα) και αντίστροφη μέτρηση «Σε 25′» στις κάρτες.
- Χρωματιστή λωρίδα ανά άθλημα, νέα εικονίδια (πόλο, στίβος, πολεμικές τέχνες, εκπομπές).
- Οι μεταδόσεις που έληξαν διπλώνονται: «Εμφάνιση προηγούμενων (N)».
- Κουκκίδα στις ημέρες που έχουν δικές σου μεταδόσεις, κολλητές επικεφαλίδες ημέρας στην «Εβδομάδα».
- Προεπισκόπηση «Ταιριάζει με N μεταδόσεις» όταν γράφεις όνομα ομάδας.
- Δόνηση αφής στα αστέρια / κουδουνάκια, ολόκληρη η γραμμή πατιέται στις λίστες.

## Αυτόματες ενημερώσεις (OTA) από το GitHub

Πώς δουλεύει, βήμα-βήμα:

1. Κάνεις **push στο `main`** του https://github.com/nikkpap/MatchMate.
2. Το GitHub Actions (`.github/workflows/release.yml`) τρέχει τα tests, χτίζει το APK
   και δημοσιεύει **Release `v0.3.N`** (N = αριθμός build) με το `MatchMate-0.3.N.apk` και το SHA-256 του.
3. Η εφαρμογή ελέγχει το τελευταίο Release: στο άνοιγμα (το πολύ 1 φορά/ώρα) και στο παρασκήνιο κάθε 6 ώρες.
4. **Πλήρως αυτόματα (OTA, προεπιλογή):** κατεβάζει το APK, ελέγχει το SHA-256 και το εγκαθιστά μέσω
   `PackageInstaller` **χωρίς πάτημα** (Android 12+). Αν είσαι μέσα στην εφαρμογή, η εγκατάσταση γίνεται
   μόλις βγεις από αυτήν, ώστε να μην κλείσει μπροστά σου. Μετά βλέπεις «Το MatchMate ενημερώθηκε στην έκδοση X ✓».
5. **Μία φορά μόνο** το Android ζητά «Να επιτρέπεται από αυτή την πηγή» για το MatchMate
   (Ρυθμίσεις → Σχετικά → Ενημερώσεις → «Άνοιγμα ρύθμισης»). Σε Android 8–11 ζητείται ένα πάτημα σε κάθε ενημέρωση.

- Χειροκίνητα: **Ρυθμίσεις → Σχετικά → Έλεγχος για ενημέρωση**. Διακόπτες: «Αυτόματος έλεγχος» και «Αυτόματη εγκατάσταση (OTA)».
- Commit με `[no release]` στο μήνυμα → build & tests χωρίς νέο Release.
- Αλλαγή γραμμής εκδόσεων (π.χ. 0.4.x): `appVersionBase=0.4` στο `gradle.properties`.
- Τα APK υπογράφονται με το ίδιο `preview-test.keystore`, οπότε κάθε Release εγκαθίσταται ως αναβάθμιση
  πάνω στην 0.2.0 / 0.3.0. Το Android απορρίπτει APK με διαφορετική υπογραφή.
- ⚠️ Το κλειδί είναι δημόσιο (μέσα στο repo). Για προσωπική χρήση είναι εντάξει· για δημόσια διανομή
  χρειάζεται δικό σου κρυφό keystore ως GitHub Secret (αλλάζοντας κλειδί απαιτείται μία απεγκατάσταση).

## Ανδρικά / Γυναικεία

- Η εφαρμογή αναγνωρίζει τα γυναικεία από την πηγή: «Γυναικών» στη διοργάνωση (π.χ. «Ευρωλίγκα Γυναικών»,
  «Α1 Γυναικών Volley League», «UEFA Champions League Γυναικών») ή «WTA» στον τίτλο. Τα υπόλοιπα θεωρούνται ανδρικά.
- **Πρόγραμμα:** φίλτρο ♂♀ Όλα / ♂ Ανδρικά / ♀ Γυναικεία και ροζ σήμα «♀ Γυναικών» στις κάρτες και στις ειδοποιήσεις.
- **Ομάδες:** π.χ. «ΠΑΟΚ · Ανδρικά» ώστε να μη σε ειδοποιεί για το γυναικείο χάντμπολ (ή το αντίστροφο).
- **Αθλήματα:** για κάθε ενεργό άθλημα διαλέγεις Όλα / Ανδρικά / Γυναικεία (π.χ. μόνο WTA στο τένις).
- **Διοργανώσεις:** φίλτρο και σήμα ♀. Οι γυναικείες διοργανώσεις είναι πάντα ξεχωριστή επιλογή.
- Οι παλιές επιλογές μένουν «Όλα», όπως λειτουργούσαν μέχρι τώρα.

## Πρώτη χρήση

1. Εγκατέστησε το `MatchMate-0.3.0.apk`, αν περιλαμβάνεται στην παράδοση.
2. Άνοιξε την εφαρμογή με ενεργή σύνδεση για να φορτωθεί το πρόγραμμα.
3. Στις **Επιλογές**, διάλεξε ομάδες και τα αντίστοιχα αθλήματα,
   διοργανώσεις ή ολόκληρα αθλήματα. Η Formula 1 και το MotoGP επιλέγονται χωριστά.
4. Στις **Ρυθμίσεις**, ενεργοποίησε την άδεια ειδοποιήσεων και την άδεια
   **Ακριβής χρόνος / Ξυπνητήρια και υπενθυμίσεις**.
5. Διάλεξε έναν ή περισσότερους χρόνους: 0, 5, 10, 15, 30, 60, 120, 180 λεπτά
   ή πρόσθεσε δικό σου χρόνο έως 1440 λεπτά. Η προεπιλογή είναι **30 λεπτά πριν**.
6. Πάτησε **Δοκιμαστική ειδοποίηση** για να ελέγξεις την εμφάνιση και τον ήχο.

Δεν προεπιλέγεται κάποια ομάδα. Χωρίς επιλογές ή μεμονωμένα κουδουνάκια
δεν προγραμματίζονται υπενθυμίσεις.

## Μπαταρία και απόδοση στην έκδοση 0.2.0

- Οι υπενθυμίσεις με ίδια ώρα συγκεντρώνονται σε ένα `AlarmManager` alarm,
  με ξεχωριστή ειδοποίηση για κάθε μετάδοση. Δεν απαιτείται δίκτυο κατά την παράδοση.
- Ο μόνιμος κατάλογος alarms συγκρίνεται με το νέο πρόγραμμα. Μόνο νέες ή
  αλλαγμένες εγγραφές επαναπρογραμματίζονται και οι αφαιρεμένες ακυρώνονται.
- Αλλαγές θέματος, αγαπημένων ή συχνότητας ανανέωσης δεν αλλάζουν τα alarms.
- Η αποκατάσταση μετά από επανεκκίνηση/αλλαγή ώρας/αναβάθμιση είναι πλήρης.
  Το πρώτο άνοιγμα κάθε νέας διεργασίας αποκαθιστά επίσης τα alarms, επειδή
  η αναγκαστική διακοπή τα διαγράφει. Τα επόμενα resumes συγκρίνουν μόνο διαφορές.
- Υπάρχουν έως 400 ενεργά χρονικά slots. Κάθε παράδοση, ανανέωση ή άνοιγμα
  γεμίζει ξανά το κυλιόμενο παράθυρο με τις επόμενες υπενθυμίσεις.
- Ο περιοδικός συγχρονισμός ενεργοποιείται μόνο με άδεια ειδοποιήσεων και
  ενεργές επιλογές ομάδας/αθλήματος/διοργάνωσης ή μελλοντικά μεμονωμένα κουδουνάκια.
  Ακυρώνεται στην παύση ή όταν δεν υπάρχει άλλη τέτοια επιλογή.
- Ο WorkManager απαιτεί σύνδεση και μπαταρία που δεν θεωρείται χαμηλή από το Android.
  Έχει περιθώριο εκτέλεσης 15 λεπτών, exponential backoff και διατηρεί την ίδια
  περιοδική εργασία στις επόμενες εκκινήσεις αντί να την αντικαθιστά.
- Το ήδη πρόσφατο πρόγραμμα αποτρέπει νέο download. Η αλλαγή ημέρας Ελλάδας
  ανανεώνει το παράθυρο των επτά ημερών. Παράλληλα αιτήματα μοιράζονται το αποτέλεσμα
  μιας επιτυχούς ανανέωσης. Το «Ανανέωση τώρα» παραμένει διαθέσιμο στο προσκήνιο.
- Το χρονόμετρο ενημερώνεται ανά λεπτό μόνο όσο η οθόνη προγράμματος είναι ορατή,
  μέσω `repeatOnLifecycle`. Φίλτρα, ομαδοποιήσεις και ευρετήρια ονομάτων αναχρησιμοποιούνται.
- Πρόγραμμα, προτιμήσεις και κατάλογος υπενθυμίσεων αποθηκεύονται σε διαφορετικά
  τοπικά αρχεία. Η αλλαγή μιας προτίμησης δεν ξαναγράφει το πλήρες πρόγραμμα.
- Δεν υπάρχει μόνιμη foreground υπηρεσία, polling ανά λεπτό στο παρασκήνιο
  ή χειροκίνητα κρατημένο wake lock. Διατηρούνται R8 και resource shrinking.

Οι λιγότερες εργασίες είναι επαληθεύσιμες από τον σχεδιασμό και τις δοκιμές.
Δεν έχει μετρηθεί ποσοστό εξοικονόμησης μπαταρίας σε πραγματική συσκευή.
Οι ανανεώσεις μπορούν να καθυστερούν σε χαμηλή μπαταρία ή Doze, οπότε οι αλλαγές
της πηγής θα ληφθούν αργότερα. Οι ήδη αποθηκευμένες υπενθυμίσεις δεν εξαρτώνται
από τον WorkManager, αλλά παραμένουν υπό τους περιορισμούς alarms του Android.

## Πώς λειτουργούν οι επιλογές

Οι επιλογές **προστίθενται**: ΠΑΟΚ + EuroLeague + F1 σημαίνει κάθε μετάδοση
που ταιριάζει σε τουλάχιστον μία επιλογή. Αν η ίδια μετάδοση ταιριάζει
σε πολλές επιλογές, προγραμματίζεται μία υπενθύμιση ανά επιλεγμένο χρόνο.

Η αναγνώριση ομάδων γίνεται από τις δύο πλευρές του τίτλου, με εξομάλυνση
τόνων, πεζών/κεφαλαίων και συγκεκριμένες εναλλακτικές γραφές. Το «ΠΑΟΚ»
δεν ταυτίζεται με το «ΠΑΟΚ Β». Ορισμένοι τίτλοι ή χορηγικές ονομασίες
ενδέχεται να απαιτούν χειροκίνητη προσθήκη ομάδας ή κουδουνάκι.

Οι χρόνοι υπολογίζονται από **την ώρα της τηλεοπτικής μετάδοσης**.
Αυτή μπορεί να προηγείται της έναρξης του ίδιου του αγώνα.
Το πρόγραμμα ερμηνεύεται στη ζώνη `Europe/Athens`, όπως οι ώρες της πηγής.
Η ώρα θερινής/χειμερινής περιόδου λαμβάνεται υπόψη μέσω `java.time`.

Αν έχει ήδη περάσει μια ώρα υπενθύμισης, δεν στέλνεται εκ των υστέρων.
Προγραμματίζονται μόνο οι επόμενες μελλοντικές ώρες.
Στις ώρες ησυχίας οι ειδοποιήσεις **παραλείπονται**, δεν μεταφέρονται αργότερα.
Ίδιες ώρες έναρξης και λήξης ησυχίας σημαίνουν κενό διάστημα.

Κάθε εγγραφή μετάδοσης διατηρεί το δικό της κουδουνάκι. Η πηγή δεν δίνει
αξιόπιστο αναγνωριστικό αγώνα για συγχώνευση διαφορετικών καναλιών ή ωρών.

## Ειδοποιήσεις με κλειστή εφαρμογή

Οι αποθηκευμένες υπενθυμίσεις χρησιμοποιούν `AlarmManager` και λειτουργούν
όταν η οθόνη είναι κλειστή ή έχεις απομακρύνει την εφαρμογή από τα πρόσφατα.
Με άδεια ακριβούς χρόνου χρησιμοποιείται `setExactAndAllowWhileIdle`.
Χωρίς άδεια χρησιμοποιείται `setAndAllowWhileIdle`, οπότε επιτρέπεται καθυστέρηση
από το Android. Η εφαρμογή εμφανίζει αυτή τη διαφορά στις ρυθμίσεις.

Η ανανέωση WorkManager είναι περιοδική και δεν εγγυάται ακριβή ώρα εκτέλεσης.
Οι αλλαγές ώρας/καναλιού ή ακυρώσεις λαμβάνονται στην επόμενη επιτυχή ανανέωση.
Δεν χρειάζεται σύνδεση τη στιγμή μιας ήδη προγραμματισμένης ειδοποίησης.

Το **Force stop / Αναγκαστική διακοπή**, τα κλειστά κανάλια ειδοποιήσεων,
το «Μην ενοχλείτε» και ειδικοί περιορισμοί μπαταρίας της συσκευής μπορούν
να εμποδίσουν την εμφάνιση. Μετά από αναγκαστική διακοπή χρειάζεται να ανοίξεις
ξανά την εφαρμογή. Η άδεια ακριβούς χρόνου δεν παρακάμπτει το «Μην ενοχλείτε».

## Πηγή δεδομένων

Σελίδα: https://www.sport24.gr/tvprogram/

Endpoint που παρατηρήθηκε να χρησιμοποιείται από τη σελίδα στις 04/10/2026:

```text
https://tv.24media.gr/service/events?accept=json&date=YYYY-MM-DD&days=7&pId=3
```

Διαβάζονται `id`, `scheduleDate`, `title`, `description`, `channel.name` και `tags`.
Δεν χρησιμοποιείται το `isLive` για φιλτράρισμα, επειδή στο δοκιμασμένο δείγμα
ήταν `false` σε όλες τις εγγραφές. Δεν υποστηρίζεται φίλτρο «μόνο ζωντανά».
Οι επαναλήψεις δεν μπορούν πάντα να αναγνωριστούν από τα διαθέσιμα δεδομένα.

Το endpoint δεν έχει επαληθευτεί ως επίσημο API τρίτων και μπορεί να αλλάξει.
Δεν υπάρχει διασύνδεση με Matchcenter, εγγύηση διαθεσιμότητας ή άδεια εμπορικής
αναδιανομής δεδομένων. Η εφαρμογή είναι ανεξάρτητη και δεν χρησιμοποιεί
λογότυπα SPORT24 ή ομάδων.

## Άνοιγμα στο Android Studio

1. Αποσυμπίεσε το ZIP.
2. **File → Open** και διάλεξε τον φάκελο `MatchMate`, που περιέχει `settings.gradle.kts`.
3. Χρησιμοποίησε Gradle JDK **17 ή 21**, και εγκατέστησε Android SDK Platform 35.
4. Περίμενε το Gradle Sync και πάτησε **Run** σε συσκευή Android 9 ή νεότερη.

Το project περιλαμβάνει τον Gradle Wrapper. Δεν περιλαμβάνει `local.properties`,
τοπικά SDK ή caches. Περιλαμβάνει `app/preview-test.keystore`, ένα **δημόσιο
κλειδί αποκλειστικά για δοκιμές**, με κωδικούς `android`. Το χρησιμοποιούν
οι παραλλαγές debug/preview, ώστε τα επόμενα builds αυτού του project να
διατηρούν την υπογραφή. Δεν πρέπει να χρησιμοποιηθεί για παραγωγή ή Play Store.
Η release παραλλαγή παραμένει χωρίς υπογραφή.

| Παράμετρος | Τιμή |
|---|---|
| Package / namespace | `gr.matchbell.app` |
| minSdk | 28 — Android 9 |
| compileSdk / targetSdk | 35 |
| Kotlin | 2.0.21 |
| Android Gradle Plugin | 8.9.2 |
| Gradle | 8.11.1 |
| Java / Kotlin bytecode | 17 |
| Compose BOM | 2024.12.01 |

```bash
./gradlew :app:assembleDebug :app:testDebugUnitTest :app:lintDebug
```

Στα Windows:

```bat
gradlew.bat :app:assembleDebug :app:testDebugUnitTest :app:lintDebug
```

Το APK παράγεται στο `app/build/outputs/apk/debug/app-debug.apk`.
Η παράδοση χρησιμοποιεί την επιπλέον παραλλαγή `preview`: περιέχει τον ίδιο
κώδικα, με R8 και αφαίρεση αχρησιμοποίητων πόρων για μικρότερο αρχείο,
και υπογράφεται με το δημόσιο κλειδί δοκιμής που περιλαμβάνεται στο project.

```bash
./gradlew :app:assemblePreview
```

Το preview APK παράγεται στο `app/build/outputs/apk/preview/app-preview.apk`.
Το APK της παράδοσης προορίζεται για προσωπική δοκιμή.
Η υπογραφή του είναι διαφορετική από την παλιά παράδοση MatchBell 0.1.0,
επειδή το προηγούμενο προσωρινό debug κλειδί δεν είναι διαθέσιμο. Το Android
δεν επιτρέπει απευθείας αναβάθμιση μεταξύ αυτών των δύο APK. Αν είναι εγκατεστημένο
το παλιό APK, **κράτησε πρώτα σημείωση των επιλογών σου**: η απεγκατάστασή του
διαγράφει τις τοπικές προτιμήσεις. Δεν έγινε απεγκατάσταση ή αλλαγή στη συσκευή σου. Για παραγωγή απαιτείται
δική σου release υπογραφή και έλεγχος σε πραγματικές συσκευές.

## Δεδομένα και ιδιωτικότητα

Οι προτιμήσεις, το πρόγραμμα και η λίστα ειδοποιήσεων που έχουν παραδοθεί
αποθηκεύονται στη συσκευή. Δεν υπάρχει λογαριασμός, analytics, διαφήμιση
ή δικός μας server. Γίνεται σύνδεση στο endpoint της 24MEDIA για το πρόγραμμα.
Τα δεδομένα διαγράφονται με εκκαθάριση δεδομένων εφαρμογής ή απεγκατάσταση.
Τα Android cloud backups για την εφαρμογή είναι απενεργοποιημένα.
